# This is “Application project” based on "Platform project"
for [FPGA Zynq board support EBAZ4205](https://github.com/botnursery/EBAZ4205-Minimum-Board-Operating-Configuration) at Vitis HLS 2022.2 
EBAZ4205 is mining board used in Ebang Ebit E9+ bitcoin miner machine. This board features 256MB DDR3 memory, 128MB NAND Flash memory, 10/100MBit Ethernet and speed grade -1 Zynq 7010
